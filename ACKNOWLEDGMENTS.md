# Acknowledgments

Tally Island is an original implementation informed by the following projects and products:

- [Gentra Island](https://github.com/Adamfatur/gentra-island): dot-style numeric presentation and the idea of useful, quiet daily tools at the notch.
- [Atoll](https://github.com/Ebullioscopic/Atoll), [AtollExtensionKit](https://github.com/Ebullioscopic/AtollExtensionKit), [AtollRPC](https://github.com/Ebullioscopic/AtollRPC), and [atoll-js](https://github.com/Ebullioscopic/atoll-js): native island interactions and extensible live activities.
- [Boring.Notch](https://github.com/TheBoredTeam/boring.notch): native media and shelf concepts; foundational to Atoll's own history.
- [Stats](https://github.com/exelban/stats): useful system metrics and the importance of controlling background work.
- [Teleprompter](https://github.com/Ebullioscopic/Teleprompter): near-camera script reading.
- [DynamicNotch](https://github.com/jackson-storm/DynamicNotch) and [Alcove](https://tryalcove.com/): compact native presentation.

Additional research included [SkyLightWindow](https://github.com/Lakr233/SkyLightWindow), [rtaudio](https://github.com/ZephyrCodesStuff/rtaudio), [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm), [OpenUsage](https://github.com/robinebers/openusage), [Open-Meteo](https://open-meteo.com/), and [OpenRouter](https://openrouter.ai/). These are not bundled dependencies or implemented integrations in v0.1. The Wick acknowledgment in Atoll had no source link; no Wick implementation was reviewed or reused.

See [the survey](docs/REPOSITORY_SURVEY.md) for the review of all 52 public repositories and explicit inclusion/defer decisions.

No source code or assets from these projects are redistributed. Apple system frameworks, SF Symbols and system fonts are used through macOS APIs. Tally's dot glyphs and app icon are drawn by its own code. Upstream names, trademarks and licenses belong to their respective owners. The authors of these projects have not endorsed Tally Island.
